# Experiment journal

Original cream/forest-green/chartreuse editorial report. A wide scatterplot faces an evidence panel, policy tabs reveal the full curve, task rows open actual patches and test failures, and an editable live lab exposes lost information. No card grid, timeline metaphor, stock template, remote fonts or raster assets. System sans-serif, Georgia italic and monospace distinguish narrative, findings and raw output.

Outside source consulted: [Observable Plot dot marks](https://observablehq.github.io/plot/marks/dot) and [mark composition](https://observablehq.github.io/plot/features/marks). The graph uses original SVG, explicit axes and the same observed-success scale for every policy. Plot is not installed; no code or assets were copied. The full accessible table exposes values independently of the chart.

Browser artifacts under docs/results/browser/ exercise actual filter requests, policy/task selection, scenario entry, responsive layouts, error recovery and keyboard focus. They are not a WCAG certification or a human evaluation study.
